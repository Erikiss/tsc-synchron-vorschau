Hosting über GitHub Pages

Diese Website ist eine statische Website: Sie besteht aus fertigen Seiten, Bildern und Schriften, die bei jedem Aufruf unverändert ausgeliefert werden. Es gibt keine Datenbank, keine Benutzerkonten und kein Kontaktformular.

Bereitgestellt wird sie über den Dienst GitHub Pages der GitHub, Inc., 88 Colin P. Kelly Jr. St., San Francisco, CA 94107, USA. Wenn Sie eine Seite aufrufen, übermittelt Ihr Browser technisch notwendige Angaben an die Server von GitHub, damit die Seite ausgeliefert werden kann:

  • Ihre IP-Adresse,
  • Datum und Uhrzeit,
  • die aufgerufene Adresse,
  • Angaben zu Browser und Betriebssystem (User-Agent) und
  • gegebenenfalls die zuvor besuchte Seite (Referrer).

Nach eigenen Angaben protokolliert und speichert GitHub die IP-Adresse von Besucherinnen und Besuchern einer GitHub-Pages-Website zu Sicherheitszwecken, unabhängig davon, ob sie bei GitHub angemeldet sind. Eine feste Speicherdauer nennt GitHub dafür nicht; für seine Sicherheitspraktiken verweist GitHub auf seine Datenschutzerklärung. Nach unserem Kenntnisstand stellt GitHub uns keine Zugriffsprotokolle zur Verfügung; wir selbst werten keine Besucherdaten aus.

Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO. Unser berechtigtes Interesse liegt in der sicheren und zuverlässigen Bereitstellung unserer Website.

GitHub verarbeitet Daten auch in den USA. Für Übermittlungen in die USA besteht ein Angemessenheitsbeschluss der EU-Kommission vom 10. Juli 2023 (EU-U.S. Data Privacy Framework, Art. 45 DSGVO); GitHub ist nach diesem Rahmen zertifiziert. Weitere Informationen finden Sie in der Datenschutzerklärung von GitHub (Englisch) (externer Link) (docs.github.com).

Ihre Rechte gegenüber GitHub können Sie nach Angaben von GitHub per E-Mail an privacy@github.com geltend machen; den Datenschutzbeauftragten von GitHub erreichen Sie unter dpo@github.com.

Domain

Die Domain tsc-synchron.de ist über die STRATO GmbH, Otto-Ostrowski-Straße 7, 10249 Berlin, registriert. Deren Nameserver ordnen den Domainnamen der Adresse des Servers zu, auf dem diese Website liegt (DNS).

04

Keine Cookies, kein Tracking

Diese Website setzt keine Cookies und nutzt keine Analyse-, Statistik- oder Werbedienste. Es gibt keine Social-Media-Plugins und keine eingebetteten Inhalte anderer Anbieter wie Videos oder Karten. Ein Einwilligungsbanner ist deshalb nicht nötig.

Schriften und Bilder werden zusammen mit der Website über GitHub Pages ausgeliefert. Ihr Browser baut dabei keine Verbindung zu Google Fonts oder anderen Servern außerhalb dieses Hostings auf.

Einstellung „Animationen anhalten“

Wenn Sie im Fußbereich der Seite „Animationen anhalten“ wählen, merkt sich Ihr Browser diese Einstellung im lokalen Speicher (localStorage, Eintrag „tsc-bewegung“). Der Eintrag bleibt auf Ihrem Gerät, wird nicht an uns übertragen und lässt sich über die Einstellungen Ihres Browsers jederzeit löschen. Die Speicherung ist für diese von Ihnen gewünschte Funktion unbedingt erforderlich (§ 25 Abs. 2 Nr. 2 TDDDG).

05

Kontakt per E-Mail

Wenn Sie uns eine E-Mail schreiben, verarbeiten wir Ihre E-Mail-Adresse, gegebenenfalls Ihren Namen und Ihre Telefonnummer sowie den Inhalt Ihrer Nachricht, um Ihre Anfrage zu beantworten.

Die E-Mail-Links auf dieser Website öffnen nur Ihr eigenes E-Mail-Programm mit einem vorbereiteten Betreff. Über die Website selbst werden dabei keine Daten übertragen; „Adresse kopieren“ legt die Adresse nur in der Zwischenablage Ihres Geräts ab.

Rechtsgrundlage ist Art. 6 Abs. 1 lit. b DSGVO, wenn Ihre Anfrage auf eine Mitgliedschaft oder ein Probetraining zielt, sonst Art. 6 Abs. 1 lit. f DSGVO (unser berechtigtes Interesse, Anfragen zu beantworten). Wir löschen Ihre Nachricht, sobald wir sie nicht mehr benötigen und keine gesetzlichen Aufbewahrungspflichten entgegenstehen, spätestens nach sechs Monaten nach Erledigung.

Unsere E-Mail-Postfächer betreibt die STRATO GmbH, Otto-Ostrowski-Straße 7, 10249 Berlin.

06

Mitgliedschaft & Formulare

Aufnahmeantrag und SEPA-Lastschriftmandat laden Sie als PDF von dieser Website herunter; dabei fallen nur die oben unter „Hosting“ beschriebenen Zugriffsdaten an. Ausgefüllt enthalten die Formulare personenbezogene Daten wie Geburtsdatum, Anschrift und Bankverbindung. Diese verarbeiten wir zur Durchführung Ihrer Mitgliedschaft und zum Beitragseinzug (Art. 6 Abs. 1 lit. b DSGVO).

Die Satzung senden wir Ihnen auf Wunsch per E-Mail zu. Dafür verarbeiten wir Ihre E-Mail-Adresse und Ihre Nachricht wie unter „Kontakt per E-Mail“ beschrieben.

Noch zu erstellen

Eine eigene Datenschutzinformation für Mitglieder nach Art. 13 DSGVO: Zwecke, Weitergabe (z. B. an Landessportbund und Verbände), Speicherdauer, Fotos von Training und Veranstaltungen. Sie gehört zum Aufnahmeantrag; hier kann sie verlinkt werden.

Sobald die Website eigene Vereinsfotos zeigt, einen Abschnitt zu Fotos und Einwilligungen ergänzen.
